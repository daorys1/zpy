## Notes for Implementation

1. **Consistency**: Choose one translation style and stick with it throughout your language
2. **Brevity**: Shorter keywords are generally preferred for programming (1-2 characters when possible)
3. **Clarity**: The translation should be immediately understandable to Chinese speakers
4. **Existing precedent**: Consider looking at existing Chinese programming languages like 易语言 (Easy Language) for inspiration
5. **Avoid ambiguity**: Make sure keywords don't conflict with common variable names
